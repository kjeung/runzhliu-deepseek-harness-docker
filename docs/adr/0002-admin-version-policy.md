# Admin version policy is anchored to the image's pinned DSH version

The admin image lets an operator install any published `@deepseek-ai/dsh` version, but every published version today is a pre-release and the registry's `latest` tag is stale in the browser-use family. So the policy pins the floor to the image's build-time `DSH_VERSION` and lets the range run upward only: no downgrades below the pin, all channels (alpha/beta/rc and the `next` tag) allowed, both browser-use packages resolved at the exact same version (never by tag; a missing same-version pairing fails the install closed), and an untested version installs in one click with automatic rollback as the safety net. "Tested" means the pin the image was built and CI-tested with; every other version is untested (decision record: [#10](https://github.com/kjeung/runzhliu-deepseek-harness-docker/issues/10); spec: [#14](https://github.com/kjeung/runzhliu-deepseek-harness-docker/issues/14)).

- **Status:** accepted, 2026-10-24
- **Considered options:** floor on the dynamic `latest` tag rejected — when upstream publishes, the tag moves past the image pin and the pin, which is the rollback target, falls out of the selectable range; a full-history range (≥ `0.1.2-alpha.2`, the token era) rejected — versions before `0.1.6-alpha.1` have no same-version browser-use package, which would force a degraded browser-desktop state; installing DSH alone when the browser-use pairing is missing rejected — it breaks the same-version pairing invariant from Q9=A; gating on npm `engines` rejected — the package publishes no `engines`/`os`/`cpu`, so compatibility is caught by a post-install health check and rollback instead.
- **Consequences:** operators cannot downgrade below the image pin (rollback is a `current` flip, not a reinstall); the writable volume holds `current` plus two old versions and is documented at ≥ 4 GB; "tested" never means "CI history", only the current build pin; the registry client must resolve each browser-use package by exact version and fail closed when that version is missing.
